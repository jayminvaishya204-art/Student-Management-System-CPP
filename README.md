# Student Management System (C++)

A beginner-friendly **Student Management System** built in **C++** to strengthen core programming fundamentals. This console-based project allows users to manage student records using arrays, functions, loops, and conditional statements without using Object-Oriented Programming (OOP).

## Features

* Add student details (Name, Roll Number, Marks)
* Display all student records
* Search a student by Roll Number
* Find the highest-scoring student
* Calculate the class average
* Menu-driven interface using `switch` statements

## Concepts Learned

* Functions
* Arrays
* Loops (`for`, `do-while`)
* Conditional statements (`if`, `switch`)
* Linear Search
* Finding the maximum value in an array
* Basic data management using arrays

## How to Run

Compile the program using a C++ compiler:

```bash
g++ student_management.cpp -o student_management
```

Run the executable:

**Windows**

```bash
student_management
```

**Linux/macOS**

```bash
./student_management
```
